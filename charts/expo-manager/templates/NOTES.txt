Before upgrading across a release that ships a new database migration, take a dump first:
  kubectl exec -n {{ .Release.Namespace }} {{ include "expo-manager.rethinkdb.fullname" . }}-0 -- \
    sh -c 'rethinkdb dump -c localhost:28015 --password-file <(echo -n "$RETHINKDB_PASSWORD") -f /tmp/pre-upgrade.tar.gz'
  kubectl cp {{ .Release.Namespace }}/{{ include "expo-manager.rethinkdb.fullname" . }}-0:/tmp/pre-upgrade.tar.gz ./pre-upgrade.tar.gz
The API runs its migrations at boot and refuses to start half-migrated; restore with
`rethinkdb restore <file> --force` if one fails.
